======================================================================
  WARP Auto & AmneziaWG — Автоматический установщик для OpenWrt
======================================================================

Поддерживаемые версии: OpenWrt 25.x (apk) и 24.x (opkg)
Целевая архитектура: MediaTek Filogic (aarch64_cortex-a53) и совместимые

ИНСТРУКЦИЯ ДЛЯ WINDOWS:
----------------------------------------------------------------------
1. Убедитесь, что ваш компьютер подключен к роутеру по кабелю или Wi-Fi.
2. Дважды кликните по файлу:
     install-windows.bat
   (или запустите install-windows.ps1 в PowerShell).
3. Выберите IP-адрес роутера:
     [1] 192.168.10.1 (по умолчанию)
     [2] 192.168.1.1  (стандартный для чистой прошивки OpenWrt)
     [3] Свой IP
4. При запросе пароля введите пароль пользователя root.
   Если роутер только что прошит и пароль еще не задавался — нажмите Enter.
5. Дождитесь завершения установки.
6. Откройте веб-интерфейс роутера:
     http://192.168.10.1/cgi-bin/luci/admin/services/amneziawg
     (или ваш IP роутера)

ЧТО ВХОДИТ В СОСТАВ ПАКЕТА:
----------------------------------------------------------------------
- kmod-amneziawg: модуль ядра AmneziaWG для Linux 6.12.87
- amneziawg-tools: утилита управления awg и сетевой протокол OpenWrt
- awg-warp-auto-quic: нативный генератор QUIC I1 (/usr/bin/quic-i1)
- luci-proto-amneziawg: LuCI веб-интерфейс, фоновый демон и пул профилей
- install.sh, upgrade.sh, uninstall.sh: скрипты управления на роутере
- awg-openwrt-feed.pem: публичный ключ подписи репозитория

Для ручной установки непосредственно на роутере:
  scp -O awg-warp-auto-release.tar.gz root@192.168.10.1:/tmp/
  ssh root@192.168.10.1
  cd /tmp && tar -xzf awg-warp-auto-release.tar.gz && cd awg-warp-auto-release && ./install.sh
